THE IDEA BEHIND DREAMER

Experience. Imagine. Improve.

A LOOP, REPEATED.
01 / EXPERIENCE

Get to know the world.

The agent takes an action and sees what happens. It stores observations, actions, and rewards as experience to learn from.

observation → action → reward
02 / IMAGINE

Practice in a learned world.

A neural network learns to predict how the world changes. Dreamer uses it to generate imagined sequences of actions and outcomes.

now ⋯→ possible futures
03 / IMPROVE

Make the next move better.

Those imagined experiences teach a policy—a rule for choosing actions—to seek more reward. The agent returns to the real environment to collect more experience.

imagination → better decisions

The illustration above explains the algorithm. The cart view replays observed environment states, not the model’s imagined states. This run uses four state measurements rather than camera images.
